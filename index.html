Project Overview

Computer vision for continuous patient activity monitoring.

The project combines video processing, movement analysis, alerting, report generation, and a desktop graphical interface into one monitoring workflow suitable for demonstrations, research, and further healthcare-AI development.

🧍

Fall Detection

Analyzes visual movement cues from live or recorded video and flags potential fall events for caretaker attention.

🎥

Activity Monitoring

Tracks significant or irregular movement patterns and records detected activity for later review.

🚨

Real-Time Alerts

Triggers alarms for important events, enabling quicker awareness of potentially critical situations.

🧾

JSON Reporting

Creates structured, timestamped activity reports that can be saved for documentation and analysis.

Core Features

Built around a simple, practical monitoring workflow.

🖥️

Graphical Interface

Users can select a video, start detection, inspect detected events, save reports, and exit through a Tkinter-based GUI.

📈

Live Activity Visualization

Displays activity information visually to help users understand what the monitoring process is detecting over time.

📐

Motion Geometry

Uses frame-level visual cues, object shapes, relative angles, distances, and motion patterns to identify unusual events.

💾

Persistent Logs

Saves activity data in JSON format so events can be reviewed later or integrated into other systems.

Detection Logic

Visual-event analysis.

The application processes video frame by frame, identifies significant movements, draws ellipses around detected regions, and evaluates relative geometry such as angles and distances. Confirmed events are logged and can trigger an alarm.

Project Purpose

Designed for monitoring research.

The system demonstrates how computer vision can support automated observation of patient movement and create structured records for caretaker review. It can serve as a foundation for future upgrades such as pose estimation, deep-learning fall detection, multi-camera tracking, cloud alerts, and hospital dashboard integration.

Important: This project is a software/research demonstration and should not be treated as a certified medical device, clinical monitoring replacement, or sole safety system without appropriate validation, security controls, clinical oversight, and regulatory review.
